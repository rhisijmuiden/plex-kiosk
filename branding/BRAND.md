# Marquee house style

Marquee is the name of this Plex kiosk appliance. The style is built for a TV
in a dark room: a deep ink background, warm "cinema marquee" amber as the brand
colour and coral for the play accent.

> NL: Marquee is de naam van dit Plex-kioskapparaat. De stijl is gemaakt voor een
> tv in een donkere kamer: diep inktzwart, warm "bioscoopbord"-amber als
> merkkleur en koraalrood als accent voor afspelen.

## Logo

| File | Use |
|------|-----|
| `logo.svg` | Mark + wordmark (admin header, docs) |
| `logo-mark.svg` | Mark only (favicon, boot splash, small sizes) |
| `png/` | Rendered PNGs (generated by `render.py`) |

The mark is a screen with a play button under an arc of five marquee bulbs.
Keep clear space of at least one bulb diameter around it. Use it on `ink` or
`surface` backgrounds only.

## Colour

| Token | Hex | Use |
|-------|-----|-----|
| `ink` | `#0E1116` | Page / screen background |
| `surface` | `#171B22` | Sidebar, cards |
| `surface-2` | `#202632` | Hover, inputs |
| `border` | `#2A3140` | Dividers |
| `text` | `#E8EAED` | Body text |
| `text-muted` | `#8B93A1` | Secondary text |
| `amber` | `#F5A524` | Brand, primary buttons, active menu item |
| `coral` | `#FF6B5A` | Accent, play, highlights |
| `success` / `danger` / `info` | `#3DD68C` / `#F2555A` / `#5AA9FF` | Status |

Text on amber buttons is `ink`, never white.

## Typography

**Inter** for everything (UI and wordmark, weight 700, slight negative tracking).
**JetBrains Mono** for versions, logs and code.

## Admin interface rules

- Navigation menu on the **left** (`sidebarWidth` 248px), logo at the top.
- Dark theme by default, light variant available (`data-theme="light"`).
- Rounded cards (`radius` 12px), generous spacing (multiples of 8px).
- Every page available in English (default) and Dutch.

Tokens for code: `tokens.css` (CSS variables) and `tokens.json`.
